## 0.0.1

* Initial release of `xp_dart` — An authentic Windows XP (Luna Blue) design system for Flutter.
* **Zero Material / Cupertino dependencies**: Built entirely upon `package:flutter/widgets.dart` and low-level custom painters.
* Core components included:
  - `XPWindow`, `XPWindowBody`, `XPStatusBar`, `XPStatusBarField`
  - `XPButton`, `XPCheckbox`, `XPRadioButton`
  - `XPDropdown`, `XPDropdownItem`
  - `XPSlider` (horizontal & vertical, pointer & box indicators)
  - `XPTextField`, `XPTextArea`, and `xpTextSelectionControls`
  - `XPGroupBox`, `XPFieldRow`, `XPFieldRowStacked`
  - `XPTabs`, `XPTab`, `XPTabPanel`
  - `XPTreeView`, `XPTreeItem`
  - `XPProgressBar` (determinate & sliding indeterminate)
  - `XPScrollbar`, `XPScrollArrowButton`
  - `XPVerticalDivider`, `XPHorizontalDivider`
  - `XPSurface`, `XPTheme`, `XPThemeData`, `XPColors`
  - `XPSvgImage`, `XPSvgAssets`
* Comprehensive test suite and golden test verification.
